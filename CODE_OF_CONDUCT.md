# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome people of every background and level of
experience, and keep discussions about the work. Harassment, insults and personal attacks are not
accepted in issues, pull requests or any other project space.

Report unacceptable behaviour privately to the maintainer through GitHub
([@turjman](https://github.com/turjman)). Reports are handled confidentially, and the maintainer may
remove contributions or block participants who break this code.
